# 소켓(Socket)

유저 프로세스와 커널의 네트워크 프로토콜 스택 사이의 인터페이스.

## 헤더

- `<sys/socket.h>` — 소켓 생성, 옵션 설정
- `<unistd.h>` — 파일 디스크립터 닫기

## 함수

### `socket()`

```cpp
#include <sys/socket.h>

int socket(int domain, int type, int protocol);
```

통신을 위한 끝점(endpoint)을 만들고, 이를 가리키는 파일 디스크립터(fd; file descriptor)를 반환한다.
fd는 프로세스에서 열리지 않은 fd 중 가장 낮은 숫자가 반환된다.

| 인수       | 설명            |
| ---------- | --------------- |
| `domain`   | 프로토콜 패밀리 |
| `type`     | 통신 방식       |
| `protocol` | 프로토콜 번호   |

#### 반환 값

| 결과 | 반환 값 | 비고         |
| ---- | ------- | ------------ |
| 성공 | fd      |              |
| 실패 | -1      | `errno` 설정 |

### `close()`

```cpp
#include <unistd.h>

int close(int fd);
```

fd를 닫는다.

| 인수 | 설명                 |
| ---- | -------------------- |
| `fd` | 닫을 파일 디스크립터 |

#### 반환 값

| 결과 | 반환 값 | 비고         |
| ---- | ------- | ------------ |
| 성공 | 0       |              |
| 실패 | -1      | `errno` 설정 |
